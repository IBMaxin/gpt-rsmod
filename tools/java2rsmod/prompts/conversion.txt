## RSMod API Quick Reference
Use ONLY these real RSMod API names. The Elvarg names DO NOT EXIST.

### Type References (use these, NOT Elvarg's Item/Animation/Graphic)
- `objs.*` — Item types (e.g. `objs.dragon_longsword`) NOT `Item(id)`
- `seqs.*` — Animation types (e.g. `seqs.human_unarmedpunch`) NOT `Animation(id)`
- `spotanims.*` — Graphic types (e.g. `spotanims.smokepuff`) NOT `Graphic(id)`
- `synths.*` — Sound types (e.g. `synths.human_unarmedpunch`) NOT `Sound.ID`
- `stats.*` — Stat types (e.g. `stats.hitpoints`) NOT `Skill.HITPOINTS`
- `timers.*` — Timer types (e.g. `timers.prayer_drain`) NOT `TimerKey.X`

### Entity Methods (use these, NOT Elvarg's methods)
- `anim(seqs.name)` — play animation NOT `performAnimation(Animation(id))`
- `spotanim(spotanims.name, height = 96)` — play graphic NOT `performGraphic(Graphic(id))`
- `is Player` / `as Player` — type check/cast NOT `isPlayer()` / `getAsPlayer()`
- `is Npc` / `as Npc` — type check/cast NOT `isNpc()` / `getAsNpc()`
- `mes("text")` — send message NOT `sendMessage()` or `getPacketSender().sendMessage()`
- `ifSetText(component, text)` — interface text NOT `sendString(id, text)`
- `ifClose()` — close interface NOT `sendInterfaceRemoval()`
- `soundSynth(synths.name)` — play sound NOT `SoundManager.sendSound()`

### Inventory (use these, NOT Elvarg's getInventory())
- `invAdd(inv, objs.name, count)` — add items NOT `getInventory().add()`
- `invDel(inv, objs.name, count)` — delete items NOT `getInventory().delete()`
- `invTotal(inv, objs.name) > 0` — check item NOT `getInventory().contains()`
- `invTotal(inv, objs.name)` — count items NOT `getInventory().getCount()`

### Stats (use these, NOT Elvarg's getSkillManager())
- `stat(stats.hitpoints)` — current level NOT `getSkillManager().getCurrentLevel()`
- `statBase(stats.hitpoints)` — base level NOT `getSkillManager().getMaxLevel()`
- `statAdvance(stats.cooking, xp)` — add XP NOT `getSkillManager().addExperience()`
- `statRandom(stats.woodcutting, low, high, 0)` — success roll

### Timers & Delays
- `actionDelay = mapClock + cycles` — delay action NOT `getTimers().register()`
- `timer(timers.name, cycles)` — start timer NOT `TimerKey.X`
- `softTimer(timers.name, cycles)` — non-blocking timer

### Combat (different class hierarchy entirely)
- `SpecialAttackMap` + `MeleeSpecialAttack` — NOT `MeleeCombatMethod`
- `queueHit(source, delay, HitType.Melee, damage)` — NOT `PendingHit`
- `manager.rollMeleeDamage(...)` — damage calc
- `manager.queueMeleeHit(this, target, damage)` — queue hit
- `manager.continueCombat(this, target)` — resume combat

### Areas
- `isWithinArea(CoordGrid(...), CoordGrid(...))` — NOT `Area` subclass or `Boundary`
